# Account Security

## Password requirements
Passwords must be at least 12 characters long and include an uppercase letter, a number, and a symbol.

## Two-factor authentication
Two-factor authentication can be enabled under Settings > Security using either an authenticator app or SMS codes.

## Locked accounts
After 5 failed login attempts, the account is locked for 15 minutes. Customers can unlock it immediately by using the link in the password reset email.
